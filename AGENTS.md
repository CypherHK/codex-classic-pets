# Repository scope

This repository packages finished Codex pet assets for public distribution. It is not the active image-generation workspace.

- Read `README.md` for current delivery status and `ASSET_RIGHTS.md` for licensing boundaries.
- Do not import or publish unfinished imagery, personal configuration, credentials, chat logs, or generation caches.
- Do not create placeholder `pet.json` or sprite sheets that appear installable.
- Each released pet must keep its `pet.json` and validated `spritesheet.webp` together, with a relative sprite path.
- Keep character identity consistent with the approved base. Record real compatibility checks; do not claim installation or validation from file presence alone.
- Do not replace the active production workspace or modify files outside this repository without explicit authorization.
- Public hosting, pushing, license selection and release publication require an explicit user request; local preparation does not authorize them.
