# 动画预览 / Animation previews

三个 ID 子目录都提供从本次发行精灵图重新编码的预览：

- `all-states.gif` / `all-states.mp4`：九组标准状态 / all standard states。
- `idle.gif`、`running-right.gif`、`running-left.gif`、`waving.gif`、`jumping.gif`、`failed.gif`、`waiting.gif`、`running.gif`、`review.gif`：单状态 / individual states。
- `idle-jump-idle.gif`：原生画格尺寸的跳跃衔接 / native-size jump transition。
- `look-loop.gif` / `look-directions.png`：十六方向 / sixteen look directions。
- `contact-sheet.png`：全部有效画格 / populated atlas cells。
- `still-*.png`：带状态与时间标记的关键帧 / timestamped stills。

这些是资源本身的动画预览，不是 Codex 应用运行录像。
